## 🚀 Core Features

### 🧬 Adaptive Neural Graph (ANG) Engine
The heart of the system. A custom deep learning architecture that:
- **Self-grows** new neurons when uncertainty is detected
- **Remembers** up to 500 candles of market memory per pair
- **Trims** low-importance features automatically (Weight Trimming)
- **Saves & loads** its brain state between sessions

### 📡 Real-Time Data Feed
- Live WebSocket connection to **Quotex** platform
- Real-time tick data with automatic reconnection
- 24-hour historical candle preload for accurate analysis
- Smart keepalive system to maintain connection during idle periods

### 🤖 Telegram Signal Bot
- Instant signal delivery to any Telegram channel or group
- Configurable confidence threshold
- Trade result tracking (Win/Loss)
- Fully customizable message templates

### 🔐 Enterprise-Grade Security
- **HWID Binding** — License tied to unique hardware fingerprint
- **Atomic Time Verification** — Fetches true time from Google servers to prevent clock tampering
- **Offline Tamper Detection** — Tracks last-known time to detect date rollback attacks
- **Version Kill Switch** — Remote kill switch via GitHub Gist; force-update all clients instantly
- **Encrypted License Keys** — HMAC-SHA256 signed keys (16-char format)

### 🧠 Brain Persistence & Updates
- User brain data is stored in `%AppData%\StockTraderAI` — completely separate from the program
- **Updating the app never erases the trained brain**
- Default base models ship with each installer; users evolve their own copy

## 📈 Signal Intelligence

Each signal is generated by combining:

1. **ANG Output** — 3-class confidence vector (BUY / SELL / HOLD)
2. **Feature Gate** — 20 technical indicators weighted by importance
3. **Explainability Layer** — Shows *why* the signal was generated
4. **Smart Mode** — Optional EMA-trend filter for high-confidence entries only
